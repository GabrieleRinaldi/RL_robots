# Clone the project

Clone the repository in the same folder where you cloned IsaacLab (next to it, not inside it):

```bash
cd ~
git clone https://github.com/GabrieleRinaldi/RL_robots.git
```

To register the project into IsaacLab, you need to enter the folder and execute:

```bash
cd RL_robots/GAIT_SCORE_BO
uv sync --extra isaacsim #need --extra isaacsim as written into the readme 
```
